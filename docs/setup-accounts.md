# Account Setup Checklist (owner action)

You create these accounts yourself, because they're tied to your identity and billing. All are free. Use one email for all of them (ideally a dedicated project Gmail).

**Never paste secrets (passwords, API keys, connection strings) into chat.** Put them directly into the hosting dashboard's environment variables, or into a local `.env` file that is git-ignored.

## Environments

- `dev`: local machine / this cloud session. MongoDB runs in memory for tests; a local MinIO stands in for storage.
- `staging`: the free tiers above (the only hosted environment at first).
- `production`: same providers, separate Atlas project, R2 buckets and keys. Created before the first real restaurant goes live.
