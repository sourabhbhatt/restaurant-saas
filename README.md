# Restaurant SaaS Platform

A multi-tenant, offline-first restaurant management SaaS: QR dine-in ordering, waiter approval, kitchen display, counter billing, subscriptions and Super Admin.

**Current stage:** Phase 1, architecture and technology decisions (no application code yet).

- [Architecture overview](docs/architecture.md): layers, ports, tenancy, offline sync
- [Implementation roadmap](docs/implementation-roadmap.md): phases and acceptance criteria
- [Account setup checklist](docs/setup-accounts.md): accounts the owner needs to create

The remaining required docs (`provider-abstractions`, `provider-migration-guide`, `database-schema`, `tenant-security`, `offline-sync`, `subscriptions`, `deployment`, `testing`) are written in the phase that builds each part.
